# 国际化目录

应用当前统一支持以下四种界面语言：

- 简体中文（`zh-CN`）
- 繁体中文（`zh-TW`）
- 英语（`en-US`）
- 日语（`ja-JP`）

业务界面通过 `context.l10n.t(key, fallback)` 读取文案。所有 key 必须在
`values/` 下的某一个资源表中唯一注册，并同时提供四种非空翻译；带动态参数的
文案使用 `{name}` 形式的命名占位符，四种语言的占位符必须完全一致。

领域层、数据层和 Android 原生层应优先返回稳定状态码或结构化枚举，由 Flutter
展示层按当前语言转换；日志、协议字段和后端原始诊断信息不作为界面静态文案处理。
应用启动时会从本地 Store 恢复语言设置，用户在设置弹窗切换语言后也应同步持久化。
用户可见的栅格图片不得内嵌需要翻译的文字；品牌图、启动图等文字统一由 Flutter
文本层绘制，已确认含文字的旧素材必须加入源码门禁，禁止重新被运行时界面引用。

`test/app/localization/localization_completeness_test.dart` 会统一检查资源 key 冲突、
四语言完整性、占位符一致性、资源注册情况、代码中引用但未定义的 key、直接写入
界面的中日韩/拉丁文案，以及 Android 系统可见资源是否覆盖全部支持语言。
`dart tool/localization_source_audit.dart` 可在不启动 Flutter 测试运行器时执行同类
源码门禁，适合提交前快速复核。
